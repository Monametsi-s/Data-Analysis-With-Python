Here is a list of the key Pandas methods mentioned in the lecture along with their explanations:
df.dtypes
To get the data type of each column in the DataFrame df.
df.describe()
To get a statistical summary (count, mean, std, min, max, quartiles) of numerical columns in the DataFrame df.
df.describe(include='all')
To get a statistical summary of all columns, including object type columns, in the DataFrame df.
df.info()
To get a concise summary of the DataFrame df, including index dtype, column data types, non-null counts, and memory usage.
